# Remnawave Node Installer

Интерактивный установщик ноды [Remnawave](https://docs.rw) для Debian / Ubuntu: чистая нода, сайт‑заглушка с SSL, Selfsteal Reality с готовым конфигом для панели, управление ядром Xray и сертификатами — всё из одного меню со стрелками.

## Запуск

Под root (`sudo -i`):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/MonopoD123/remnanode-installer/main/install.sh)
```

## Возможности

- **Чистая нода** — Docker, `docker-compose.yml` из панели и запуск, без лишних вопросов.
- **Нода + сайт‑заглушка** — nginx, сертификат Let's Encrypt с автопродлением, фаервол UFW.
- **Selfsteal Reality** — нода, сайт‑заглушка и готовый Config Profile за один проход:
  - случайный порт для Hosts при каждой генерации, порты не повторяются;
  - ключи x25519 и shortId генерируются автоматически;
  - сайт открывается по `https://домен` сразу после установки;
  - встроенная диагностика «почему не открывается сайт».
- **Сайты‑заглушки на выбор** — «Радио», игра «Курятник», случайный из списка или свой zip по ссылке.
- **Ядро Xray** — установка любой версии из релизов XTLS/Xray-core с проверкой SHA‑256 и откатом на встроенное.
- **Сертификаты для gRPC/TLS** — проброс `/etc/letsencrypt` в контейнер ноды и перезапуск после продления.
- **rkn-guard** — запуск стороннего установщика [Flecksis/rkn-guard](https://github.com/Flecksis/rkn-guard).
- **Интерактивное 3D‑меню** — навигация стрелками, быстрый выбор цифрой, статус сервера в шапке; на узких экранах автоматически упрощается.

## Требования

- Debian 11+ или Ubuntu 20.04+ (нужен `apt`)
- Доступ root
- Для сайта и Selfsteal: домен с A‑записью на IP ноды (в Cloudflare — без проксирования, серое облако) и свободный порт 80 для выпуска сертификата
- Нода, созданная в панели Remnawave (**Nodes → Management → «+»**)

## Selfsteal Reality: как это работает

Reality маскируется под **ваш собственный домен**: nginx с настоящим сертификатом отдаёт сайт‑заглушку на `127.0.0.1:<локальный порт>`, а Xray показывает его всем, кто не является вашим клиентом.

```
клиент ──► :<порт Reality> Xray ──► свой клиент → VLESS
                                └─► чужой / сканер → nginx 127.0.0.1:<локальный порт> → сайт
```

- Если порт Reality **случайный**, nginx дополнительно публикует сайт на 443 — домен работает как обычный сайт.
- Если выбран **443**, его занимает Xray, и сайт открывается через Reality после применения профиля к ноде.

### Установка (пункт 3 → 1)

1. Создайте ноду в панели и скопируйте её `docker-compose.yml` кнопкой **«Copy docker-compose.yml»**.
2. Запустите установщик, выберите **3 → «Установить ноду + Selfsteal»** и пройдите 5 шагов:
   подготовка сервера → нода → порт Reality → сайт и сертификат → запуск.
3. Скрипт выведет готовый Config Profile и настройки хоста.

### Что сделать в панели

1. **Config Profiles** → создать профиль → вставить JSON, выведенный скриптом.
2. **Nodes** → ваша нода → выбрать профиль и отметить inbound `VLESS_REALITY_SELFSTEAL_<порт>`.
3. **Hosts** → создать хост:

   | Поле | Значение |
   |---|---|
   | Inbound | `VLESS_REALITY_SELFSTEAL_<порт>` |
   | Address | ваш домен |
   | Port | порт из вывода скрипта |
   | SNI | ваш домен |
   | Fingerprint | `chrome` |

4. **Internal Squads** → добавить inbound в сквад пользователей.

Нужен ещё один хост на другом порту — **3 → «Новый конфиг для Hosts»**: новый случайный порт, свежие ключи и shortId.

### shortId

Генерируется автоматически. Вручную — любая hex‑строка чётной длины до 16 символов:

```bash
openssl rand -hex 8
```

## Где что лежит

| Путь | Содержимое |
|---|---|
| `/opt/remnanode/docker-compose.yml` | Конфиг ноды из панели |
| `/opt/remnanode/docker-compose.override.yml` | Своё ядро Xray и сертификаты (создаётся скриптом) |
| `/opt/remnanode-selfsteal/<порт>-profile.json` | Готовый Config Profile |
| `/opt/remnanode-selfsteal/<порт>-inbound.json` | Только inbound — для добавления в существующий профиль |
| `/opt/remnanode-selfsteal/<порт>-host.txt` | Настройки хоста, публичный ключ, shortId |
| `/var/www/<домен>/` | Файлы сайта‑заглушки |
| `/etc/nginx/sites-available/<домен>.conf` | Конфиг nginx |
| `/etc/letsencrypt/live/<домен>/` | Сертификат |
| `/var/lib/remnanode/xray` | Своё ядро Xray |
| `/etc/remnanode-installer.conf` | Состояние установщика (домен, порты) |

## Если сайт не открывается

Запустите **3 → «Проверить сайт»** — скрипт проверит DNS, nginx, сертификат, локальный target и все порты Reality и подскажет, что не так. Частые причины:

- **A‑запись указывает не на сервер** или домен проксируется Cloudflare.
- **Порт Reality никто не слушает** — профиль с этим inbound ещё не назначен ноде в панели.
- **Порт закрыт снаружи** — откройте его в фаерволе хостера (UFW скрипт настраивает сам).
- **Порт 80 занят** другим процессом — сертификат не выпустится.
- **Нода не запустилась** — смотрите логи (пункт 6), чаще всего это ошибка в JSON профиля.

## Удаление

Пункт **11** — удалить ноду (контейнер, `/opt/remnanode`, по желанию своё ядро Xray) или сайт‑заглушку (конфиг nginx, файлы, по желанию сертификат и Selfsteal‑конфиги).

## Важно

- Порт ноды (`NODE_PORT`) должен быть открыт **только для IP панели** — скрипт предлагает настроить это в UFW.
- rkn-guard — сторонний скрипт; запускайте его, только если доверяете автору.
- Скрипт рассчитан на чистый сервер. На сервере с уже настроенным nginx или другими сервисами на портах 80/443 проверьте конфликты перед установкой.
